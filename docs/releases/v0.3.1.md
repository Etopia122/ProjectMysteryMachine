**Project: Mystery Machine v0.3.1**

A native Windows PC port of *Scooby-Doo! Night of 100 Frights*.

**This release contains no game data.** You need your own copy of the game —
the USA GameCube release (disc ID `GIHE78`) as a plain `.iso` or `.gcm`.

**What's new since v0.3.0**

- **Recomp Achievements.** The game reports the first 20 achievements through
  RecompLauncher as you earn them, so they appear on the game's page and on the
  leaderboards. Cheats and a save loaded mid-session mark the run casual, and
  the snack and area milestones count only the 29 real areas, so the
  out-of-bounds area can no longer inflate them.
- **The release carries its checksum.** `ProjectMysteryMachine.zip.sha256` is
  attached beside the archive; the hash and byte size are at the bottom of
  these notes.
- **Builds with a current MSYS2.** The port failed to compile with the current
  mingw-w64 headers and GCC 16 (`strchr`/`strrchr`/`strstr` are now overloaded)
  and generated duplicate symbol stubs; both are fixed.
- The launcher's Windows version resource says 0.3.1.

**How to play**

1. Extract `ProjectMysteryMachine.zip` (or install it from RecompLauncher).
2. Run `scooby_launcher.exe`, choose your disc image and press **Extract game
   files** (it reads the image locally; the files stay in `data/` beside it).
3. Press **Play**.

**What is in the archive**

- `scooby_launcher.exe` — extracts the disc, edits settings, starts the game.
- `scooby.exe` — the game, built without a console window.
- `SDL2.dll`, `libwinpthread-1.dll` — runtime DLLs.
- `recomplauncher.json` — one-click setup for RecompLauncher.
- `licences/` — the fan-project notice and the SDL2, winpthread and FFmpeg
  licence texts, plus `README.txt`.

**A note on VirusTotal**

The binaries are unsigned, and unsigned MinGW builds draw generic heuristic
flags rather than a specific malware family. Per-file results and the
false-positive reports are in
[`docs/false-positive-reports.md`](https://github.com/Etopia122/ProjectMysteryMachine/blob/HEAD/docs/false-positive-reports.md).
